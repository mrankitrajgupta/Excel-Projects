# Excel for Business Specialization – Assignment Projects

This repository contains Excel assignment projects completed as part of the **Excel for Business Specialization** course.

## Overview
These projects demonstrate practical applications of Microsoft Excel through business-related tasks, data management, calculations, analysis, and automation.

## Skills Demonstrated
- Excel Formulas and Functions
- Data Validation and Drop-down Lists
- Conditional Formatting
- Excel Tables and Named Ranges
- Data Management and Analysis
- Lookup Functions
- PivotTables and Dashboards
- VBA Macros and Automation

## Projects
Each project includes an Excel workbook containing the completed assignment, along with documentation describing its objective, tasks, Excel skills, formulas, and outcomes.

## Purpose
To strengthen practical Excel skills by completing hands-on business assignments and building a portfolio of Excel projects.

**Course:** Excel for Business Specialization
