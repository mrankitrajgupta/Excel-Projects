# Bike Sales Analysis Dashboard | Microsoft Excel

## Project Objective
Analyze bike sales data to identify customer purchasing patterns and explore how income, gender, age, commute distance, and homeownership relate to bike purchases.

## Tasks Performed
- Imported the raw dataset into a separate Working Sheet for data preparation.
- Cleaned the dataset and removed duplicate records to improve data quality.
- Created calculated age groups using four age brackets:
  - Early Adulthood (25–34)
  - Mid-Adulthood (35–49)
  - Late Adulthood (50–64)
  - Senior Adults (65–89)
- Created PivotTables to summarize and analyze customer demographics and purchasing patterns.
- Analyzed average income by gender and bike purchase status.
- Compared bike purchase patterns across commute distances and age groups.
- Created PivotCharts to visualize key findings.
- Designed an interactive dashboard with multiple charts and slicers.
- Added slicers for Homeowner, Marital Status, Region, and Education.
- Connected all slicers to the dashboard charts using Report Connections for interactive filtering.

## Key Findings
- Analyzed a dataset containing 1,002 customer records, with 483 bike purchases and 519 non-purchases.
- Customers who purchased bikes had higher average incomes across both genders.
- Mid-Adulthood customers (35–49) represented the largest number of bike purchasers among the age groups.
- Customers with a commute distance of 0–1 miles showed the highest number of bike purchases.
- Homeowners accounted for 684 records, compared to 318 non-homeowners.
- Purchasing patterns varied across age groups and commute distances.
